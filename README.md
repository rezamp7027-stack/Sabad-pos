# سبد | Sabad POS

نرم‌افزار دسکتاپ فارسی برای مدیریت سوپرمارکت در ویندوز، با واحد پول تومان و طراحی آفلاین‌محور.

## وضعیت پروژه

این مخزن در حال توسعه است. نسخهٔ فعلی اسکلت عملیاتی اولیه است و تا قبل از استفادهٔ تجاری باید آزمون‌های کامل، بررسی چاپگرها، بازیابی پشتیبان و گردش‌های مرجوعی انجام شود.

## امکانات پایه

- داشبورد روزانه و شمارش کالاهای کم‌موجود
- ثبت و ویرایش کالا با بارکد یکتا، دسته‌بندی، واحد، قیمت خرید و فروش
- صندوق فروش با پشتیبانی از بارکدخوان USB در حالت صفحه‌کلیدی
- ثبت اتمیک فروش و کسر موجودی در تراکنش دیتابیس
- ثبت فاکتور خرید از تأمین‌کننده و افزایش موجودی
- ثبت پرداخت به تأمین‌کنندگان و نمایش مانده بدهی هر تأمین‌کننده
- ثبت مرجوعی کامل و جزئی فاکتور؛ پشتیبانی از چند مرحله مرجوعی جزئی، سقف مقدار قابل مرجوعی، بازگشت موجودی و اصلاح گزارش سود
- فروش اعتباری با ثبت خودکار حساب مشتری، ثبت دریافت از مشتری و محاسبه مانده بدهی/بستانکاری
- ویرایش تعداد و قیمت واحد در صندوق
- ثبت هزینه، گزارش فروش و برآورد سود بر اساس بهای تمام‌شده ثبت‌شده
- گزارش حساب مشتریان اعتباری و مانده بدهی تأمین‌کنندگان
- گردش موجودی، پشتیبان‌گیری از دیتابیس و بازیابی اعتبارسنجی‌شده با ساخت خودکار نسخه ایمنی قبل از جایگزینی
- چاپ رسید ساده و تولید تصویر برچسب بارکد

## اجرا در ویندوز

1. Python 3.11 یا 3.12 را نصب و گزینهٔ Add Python to PATH را فعال کنید.
2. در پوشهٔ پروژه، PowerShell را باز کنید.
3. فرمان‌های زیر را اجرا کنید:

    py -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    python main.py

## ساخت فایل اجرایی

    pip install pyinstaller
    pyinstaller --noconfirm --windowed --name SabadPOS --collect-all barcode main.py

## طراحی فنی

- رابط دسکتاپ: Python و PySide6 با چیدمان راست‌به‌چپ
- ذخیره‌سازی: SQLite محلی؛ بدون نیاز به اینترنت هنگام کار روزمره
- مبلغ‌ها: عدد صحیح برحسب تومان
- فروش و خرید: تراکنش دیتابیس برای جلوگیری از ثبت ناقص
- پشتیبان‌گیری: SQLite backup API برای گرفتن نسخهٔ سازگار از دیتابیس فعال

## ساخت خودکار نسخهٔ ویندوز

در GitHub Actions، گردش‌کار `Windows executable` پس از هر push به شاخهٔ `main` فایل اجرایی را روی Windows می‌سازد. خروجی در بخش Actions همان اجرا، با نام `SabadPOS-Windows` و به‌صورت Artifact قابل دریافت است؛ این Artifact موقت است و ۱۴ روز نگهداری می‌شود. این فرایند ساخت را بررسی می‌کند، اما جایگزین آزمایش دستی برنامه روی دستگاه صندوق و چاپگر واقعی نیست.

## آزمون‌ها

گردش‌کار `Python checks` کد را کامپایل می‌کند و آزمون‌های تراکنش فروش، جلوگیری از فروش بیش از موجودی، خرید، بارکد تکراری، مرجوعی کامل و چندمرحله‌ای، جلوگیری از مرجوعی بیش از مقدار فاکتور، حساب اعتباری مشتری و تسویه، پرداخت تأمین‌کننده، پشتیبان‌گیری و بازیابی نسخهٔ پشتیبان، و محاسبهٔ سود تقریبی را اجرا می‌کند.

## محدودیت‌های شناخته‌شده

این پروژه هنوز جایگزین سامانهٔ مالیاتی یا نرم‌افزار حسابداری تأییدشده نیست. مانده حساب مشتری، گردش نقدی صندوق و مانده بدهی تأمین‌کننده به ثبت‌های داخل برنامه وابسته‌اند و تطبیق خودکار با بانک/کارت‌خوان ندارند. بستن شیفت صندوق، ردیابی تاریخ انقضا/بچ، مرجوعی خرید به تأمین‌کننده و کار هم‌زمان چند صندوق هنوز پیاده‌سازی نشده‌اند. پیش از استفاده با پول واقعی باید سناریوهای فروش، کمبود موجودی، مرجوعی، قطعی برق، بازیابی نسخهٔ پشتیبان، دقت چاپ رسید و اندازهٔ برچسب روی چاپگر واقعی آزمایش شوند.
